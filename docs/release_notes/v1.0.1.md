# LeanType Voice Plugin v1.0.1

Maintenance and feature update for the **LeanType Voice Plugin**, bringing automatic spoken language detection fixes, performance tuning, and custom vocabulary prompt support.

---

### 🚀 Highlights & Improvements

- **Auto Spoken Language Detection:** Fixed Whisper JNI decoding pipeline to seamlessly detect and transcribe spoken languages in a single pass without early exits.
- **Configurable CPU Inference Threads:** Added support for dynamic CPU thread allocation (2, 4, 6, 8 threads) from the host keyboard to optimize inference speed or save battery.
- **Vocabulary & Context Prompt Support:** Enabled Whisper initial prompt conditioning via IPC, allowing users to supply custom names, acronyms, jargon, and technical keywords for improved recognition accuracy.

---

### 📦 Setup & Updates

1. Download and install `voice_plugin.apk` from the release assets below.
2. In **LeanType Keyboard Settings > Voice input**, configure your desired CPU threads, custom vocabulary prompt, and language preferences.
