# LeanType Voice Plugin v1.0.3

Performance and speech processing update for the **LeanType Voice Plugin**, introducing native ARM hardware vector acceleration, adaptive audio silence trimming, and side-by-side development support.

---

### Highlights & Improvements

- **ARM Hardware Vector Acceleration (Dot Product & FP16):** Configured native `-DGGML_CPU_ARM_ARCH=armv8.2-a+dotprod+fp16` for `arm64-v8a` builds. Quantized matrix operations in `libggml-cpu.so` now execute using native `sdot` hardware vector instructions, delivering a 2x to 3x speedup on GEMM compute across modern 64-bit ARM mobile CPUs.
- **Adaptive Silence Trimming with Safety Margins:** Implemented pre-inference audio boundary detection in `WhisperEngine`. Automatically detects speech onsets and endpoints, stripping unneeded leading and trailing silence while preserving a generous 300ms safety padding on both ends to protect quiet consonants and breath onsets. Internal pauses within sentences remain 100% intact, preventing dead-air hallucination while cutting inference duration by 50% to 75%.
- **Side-by-Side Debug Packaging:** Configured `.debug` package suffix for debug builds (`com.leanbitlab.leantype.voice.offline.debug`) so testers and developers can run experimental builds alongside official release installations without package or signature conflicts.

---

### Setup & Updates

1. Download and install the APK matching your device architecture (or universal `voice_plugin.apk`) from the release assets below.
2. In **LeanType Keyboard Settings > Voice input**, select your desired CPU threads, custom vocabulary prompt, and language preferences.
