# LeanType Voice Plugin v1.0.0

Initial release of the **LeanType Voice Plugin**, providing fast, 100% offline on-device speech-to-text recognition for [LeanType Keyboard](https://github.com/LeanBitLab/LeanType).

---

### 🚀 Highlights

- **Offline Whisper Engine:** Native [whisper.cpp](https://github.com/ggerganov/whisper.cpp) integration with `-O3` compilation and ARM64 NEON optimizations.
- **AIDL IPC Interface:** Standardized `IVoiceEngine` / `IVoiceCallback` contract with real-time `ParcelFileDescriptor` audio streaming.
- **Async Model Management:** Non-blocking background model imports, fast binary header validation, and on-demand unloading.
- **100% Private:** Zero network permissions required; all voice data stays strictly on-device.
- **Optimized Binary:** Minified via R8/ProGuard with multi-ABI support (`arm64-v8a`, `armeabi-v7a`, `x86_64`).

---

### 📦 Setup

1. Download and install `voice_plugin.apk` from the release assets below.
2. Select or import your preferred Whisper model in **LeanType Keyboard Settings > Voice Typing**.
