# LeanType Voice Plugin v1.0.2

Maintenance and packaging update for the **LeanType Voice Plugin**, adding per-ABI APK splits, R8 signature keep rules, and a branded adaptive launcher icon.

---

### Highlights & Improvements

- **Architecture-Specific APK Splits:** Enabled ABI splits (`arm64-v8a`, `armeabi-v7a`, `x86_64`) alongside the universal `voice_plugin.apk` so users can install smaller device-specific packages.
- **R8 Compatibility Fixes:** Preserved reflection attributes and generic signatures in `proguard-rules.pro` for release builds.
- **Branded Adaptive Icon & Docs:** Added the LeanType adaptive icon with microphone badge and updated README system requirements, model comparison, and setup documentation.

---

### Setup & Updates

1. Download and install the APK matching your device architecture (or universal `voice_plugin.apk`) from the release assets below.
2. In **LeanType Keyboard Settings > Voice input**, configure your desired CPU threads, custom vocabulary prompt, and language preferences.
