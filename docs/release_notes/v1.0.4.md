# LeanType Voice Plugin v1.0.4

Compatibility update for the **LeanType Voice Plugin**: devices with an older 64-bit CPU now get a clear message instead of a crash, and a compat APK is available for them.

---

### Highlights & Improvements

- **No More Crash on Older CPUs:** Since v1.0.3 the 64-bit build needs the ARMv8.2 dot-product and FP16 instructions (Cortex-A55/A75 class, roughly 2018 and newer). The plugin now checks the CPU before it loads the native library. If the instructions are missing, the voice session ends with a message that names the compat APK, instead of the plugin process being killed by an illegal instruction.
- **New Compat arm64 APK:** `voice_plugin-arm64-v8a-compat.apk` is built for plain ARMv8-a with NEON, so it runs on every 64-bit ARM CPU (for example Cortex-A53, A57, A72 or A73 only devices such as Snapdragon 835 and 660 class phones). It is a little slower than the standard build. It is released next to the other APKs and installs over the current plugin.
- **Documentation:** The README and the model catalog now list the official LeanType Whisper models, use the menu names of the app, and describe the voice options (silence timeout, transcribe while speaking, keep model in memory), the on-demand battery behavior, troubleshooting, and the CPU requirement.

---

### Setup & Updates

1. Download and install the APK matching your device architecture (or the universal `voice_plugin.apk`) from the release assets below. On a 64-bit device with an older CPU, use `voice_plugin-arm64-v8a-compat.apk` instead. This is also what the message "CPU lacks the ARMv8.2 dot-product and FP16 instructions" asks for.
2. In **LeanType Keyboard Settings > Plugins > Voice Input**, select your desired model, CPU threads, custom vocabulary prompt, and language preferences.
